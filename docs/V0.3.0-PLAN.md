# v0.3.0 Plan — "You can actually step away"

This plan comes out of a full four-dimension audit of the codebase
(core pipeline, user-facing surfaces, safety/privacy, tests/CI/release),
performed 2026-07-02. Every finding below was verified in source at the
cited location, not assumed.

## The governing criterion

Supervisor's promise is trust-while-absent: *"Auto mode takes you out of
the loop. Supervisor takes your place."* The products people can't live
without (the Plaid/Wispr Flow class) share one pattern: **invisible until
the exact moment of need, perfect in that moment, invisible again.**
For Supervisor that means three non-negotiables:

1. **It never lies about whether it's watching.** A green dot with a dead
   API key is worse than no product.
2. **It never does the one catastrophic thing itself.** Pausing the wrong
   process, killing Claude Desktop, replay-storming on `--resume`, or
   typing into a composer the user is using — each is a delete-the-app
   moment.
3. **The moment of need is self-contained.** The notification/hover IS
   the interface: what happened, what Supervisor did, one-tap undo.

v0.3.0 is scoped to make those three true. Feature breadth comes after.

Full details live in the PR descriptions of the implementing changes.

### Honest-state UX (P1)

- No way to quit/restart Supervisor from any UI; "Restart Supervisor" is a stub shown exactly when needed (red state).
- Crashed main app leaves an orphaned heartbeat writing forever → icon stays green (no parent-liveness check).
- Global pause leaves hover saying "Watching. All clear" and icon green.
- Notifications: no actions, no dedup, no rate limit, fresh UUID each time; "paste this" answers shipped inside truncated banners.
- AX "Skip for now" never persisted → full onboarding wizard every launch for notify-only users.
- Idle loop burns one model call per minute per idle session forever; medium-confidence proposals re-banner every 60s with no dedup and never trip the stop counter.
- Tail lifecycle: every historical JSONL held open forever (fd exhaustion for exactly the power users this targets).
- Paused-state Resume button stomped by other sessions' activity (single global activity enum).
- INSTALL reset instructions delete the wrong (legacy) Keychain service.
- README links to DESIGN.md, which doesn't exist in the repo.

### Safety hardening (P1/P2)

- Injected text (QuestionAnswerer answers, `wrong_trajectory` redirects, dispatcher proposals) reaches the composer with **no deterministic harm screen**; GitHub issue bodies (third-party-writable) feed the dispatch prompt unfenced.
- InjectionLedger is in-memory only: restart or `--resume` re-opens the self-authorization gap it exists to close.
- Injection provenance marker (`SupervisorInjectionMarker.wrap`) is a no-op — the driven session still receives Supervisor text as operator text.

### Test/CI/release engineering (P2)

- The 95/95 calibration gate is prose: `testCalibrateFullCorpus` contains zero assertions and cannot fail.
- CI runs no calibration, no canaries, and skips the 90 Linux-runnable Python hook tests entirely.
- Version is hardcoded 0.1.0 forever; `Package.resolved` gitignored; no release checklist; no tags in history.
- E2E test and calibration harness re-implement production wiring (drift risk); `SafeRoots` / `LLMConversationMatcher` have zero tests; SafeRoots is dead code (never called).
- FakeClaudeCLI predates the modern transcript format — no tool_result, no sidechains, no resume shape.

## The plan

### Wave 1 — pipeline truth (this PR)

1. **Transcript-format correctness** (P0-6): parse `isSidechain`/`isMeta`;
   never emit them as owner prompts; skip `<command-*>`/compact-summary
   content in the parser and in SessionObjective. This is the foundation
   the authorization anchor sits on.
2. **Backfill/replay protection** (P0-1): first-tail of a stale or large
   transcript seeks to EOF (head-parsed for sessionStart/objective only);
   a hard event-age gate in the triage decision path drops interventions
   whose triggering event is older than ~2 minutes.
3. **Signal targeting** (P0-2): signal the session-id-confirmed handle;
   remove the Claude-Desktop PID fallback from every signal path;
   signal the process group so the forked child actually stops.
4. **Redaction pre-encoding** (P0-5): redact message/system plaintext
   before JSON encoding (keep the body pass as belt-and-suspenders); add
   PEM, generalized connection-string, npm/GitLab/Google/`ghs_`,
   standalone-AWS-secret patterns.
5. **DeterministicCatch precision** (P0-7): heredoc- and quote-aware
   subcommand splitting; check every path argument of `rm -rf`.
6. **CI: run the Python hook tests** on an ubuntu job (fastest feedback
   in the repo); corpus-shape assertion test so fixture drift fails.
7. **Docs truth**: DESIGN.md link, INSTALL Keychain reset services,
   CONTRIBUTING stale test count.

### Wave 2 — money and honesty

8. **Cost recording at the choke point** (P0-4): record every
   `createMessage` (all providers, all call sites) inside LLMClient;
   per-provider pricing; token counts when price unknown.
9. **The daily cap, for real** (P0-4): one gate before every model call;
   at cap → deterministic-catch-only mode + one persistent "stopped at
   your cap" banner. The README claim becomes true.
10. **Failure visibility** (P0-3): consecutive-failure counter →
    `.degraded` hover state (amber, "Can't reach <provider>"), heartbeat
    `networkDown` actually written, one notification, clear on success.
11. **Idle-loop economics**: exponential backoff on idle re-triage after
    consecutive all-clears; proposal-hash dedup on medium banners.

### Wave 3 — lifecycle dignity and the moment of need

12. Quit/Restart that work, heartbeat parent-liveness (`getppid`),
    paused-state honesty on every surface, AX-skip persistence.
13. Actionable notifications (Resume / Copy answer / Open recovery doc),
    per-session threading, dedup.
14. Injection harm screen: deterministic deny-list in front of every
    injected string; fence third-party issue bodies as quoted data.
15. Tail lifecycle: recency-filtered discovery, inactivity-closed tails.

### Wave 4 — proof and release

16. Calibration ratchet: per-category assertions at today's measured
    baseline (regressions fail; the 95/95 gap closes by raising the
    ratchet, not by prose).
17. Headless dogfood suite in CI (no key, no AX): destructive-pause full
    wire, impersonation-gap replay, session churn (resume/rename/truncate),
    idle→dispatch→inject against FakeClaudeCLI, queued-when-typing,
    crash/health walk, release-artifact smoke.
18. Version stamping from git describe, committed `Package.resolved`,
    versioned DMG name, release checklist, nightly calibration job.

## Dogfooding contract

Every wave ends with the same ritual: build the app in CI, run the full
suite plus the headless dogfood scenarios, and walk the artifacts a real
user touches (hover copy, banner copy, recovery doc, trace log) reading
them as a stranger. A wave ships only when the scenario list for it
passes and no earlier scenario regressed.

## What we will NOT do in v0.3.0

- No new feature surfaces (no settings window redesign, no multi-platform).
- No rubric loosening; calibration ratchets only tighten.
- No claim in README/INSTALL that the code doesn't keep. Docs and code
  move in the same commit or the claim comes out.
